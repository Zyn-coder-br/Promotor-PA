# Promotor PA V04

Implementado:
- Catálogo com busca por nome, EAN e empresa.
- Paginação de 10 produtos por página.
- Interface em lista tipo extrato.
- Botão de assistência fixo no canto inferior direito.
- Adicionar produto, marcar/desmarcar itens e excluir selecionados.
- Navegação inicial para Início, Produtos, Vencimentos e Trocas.

A exclusão exige autenticação e restringe os registros ao usuário logado.
